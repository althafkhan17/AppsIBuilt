# ☕ Chai Timer

A tiny Pomodoro-style focus timer with a chai cup that empties as you work.

**Live:** https://althafkhan17.github.io/AppsIBuilt/chai-timer/

## Features
- Focus (25 min), Chai Break (5 min), Long Break (15 min) modes
- Animated chai cup progress
- Daily session counter saved in localStorage
- Sound alert when a session ends
- Pure HTML, CSS and JavaScript, no dependencies

## Run locally
Just open `index.html` in a browser.
